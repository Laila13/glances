## 🎯 Escopo do Projeto
Este projeto analisa o software livre **Glances** e propõe uma extensão mínima viável (MVP): um **Módulo Preditivo de Esgotamento de Disco (Predictive Disk Space)**, que calcula em quantas horas o armazenamento atingirá sua capacidade máxima.

## 📁 Estrutura de Pastas do Trabalho
O repositório foi organizado rigorosamente conforme as especificações exigidas:
* [`/discovery`](./discovery): Descrição do sistema, JTBD, Personas e Mapa de Empatia.
* [`/requirements`](./requirements): Definição do MVP, Backlog e Cenários de Teste.
* [`/diagrams`](./diagrams): Diagramas UML textuais em Mermaid.
* [`/ai-usage`](./ai-usage): Relatório de uso crítico de IA.
